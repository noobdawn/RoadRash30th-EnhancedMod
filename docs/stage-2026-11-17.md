## 已完成

| 范围 | 最终行为 |
| --- | --- |
| 长跑基础 | 可选仅 AI、仅玩家或所有人；通过前移摩托车引导奔跑，超时恢复上车独立可配 |
| 长跑显示与稳定性 | 修复卸载路段后的碰撞访问；重新加载时同步人物朝向并清除旧侧倾；倒地车辆可隐藏，长跑预设默认开启 |
| AI 跑步 | 按原骑行车道偏好与车道内偏移选线；独立配速、冲刺、有限追赶和换线；不提前预判弯道，不增加攻击或追击互动 |
| 跑速与交通 | 玩家/AI 跑速取消 8 倍限制；同向、对向普通交通车分别调速；疯狂司机增加换线并允许向路肩/人行道选线 |
| Fix 修复 | 音乐音量串扰与翻滚闪奔跑动画分别开关，普通比赛及长跑均适用，默认开启 |
| 正式界面 | WPF / .NET 10 / CommunityToolkit.Mvvm 8.4.0；八类导航、卡片布局、实时摘要、折叠高级参数、固定底栏 |
| 设置管理 | 统一模型与预设，兼容旧 INI、继续使用配置版本 9；恢复默认设置保留目录并支持撤销，关闭时保存有效草稿 |
| 分发与兼容 | 自包含 x64 启动器，原增强器经独立 Framework 兼容程序调用；玩家无需安装 SDK、现代 .NET Desktop Runtime 或 WebView2 |

AI 的近距离避让保留交通碰撞机会，不保证绕过每一辆车。游戏内汽车继续沿用摩托车的基础物理；“泥头车”是玩法组合，不保证赛道具有真实卡车素材。
