# WPF 工作台

2026-11-17 将已确认的网页“工作台”布局落地为原生 Windows 启动器。正式界面采用 WPF、.NET 10 与 CommunityToolkit.Mvvm 8.4.0。旧 WinForms 页面仅保留用于既有回归和诊断，正常启动不会实例化旧窗口。

## 页面与设置

左侧依次为比赛设置、长跑模式、车辆与碰撞、车手与战斗、道路与交通、画面设置、Fix 修复、工具与调试。右侧摘要与中间表单共用 `SettingsStore`，预设修改同一个模型。罕用参数放入折叠区；依赖选项关闭时，关联编辑框禁用但保留值。

`config/launcher_settings.example.ini` 作为内嵌资源，是出厂默认值的唯一来源。`Schema.cs` 定义字段名称、说明、类型、范围和依赖。`Settings.cs` 管理 INI、校验、迁移及预设。继续保存版本 9 和原键名；特别是 `roadWidth` 与摩托车配置仍保存 UI 索引，在应用时转换为实际倍率和车辆 ID。

底部恢复默认设置保留游戏目录，可撤销到重置前完整快照。设置修改是草稿，应用前不修改游戏文件；正常关闭保存有效草稿。无效输入禁止应用，关闭时可选择放弃无效草稿。Fix 开关不会被玩法预设覆盖，恢复出厂设置则按默认值开启。

跑步速度保留原生数值表示限制和一位小数精度，超过 8 倍可输入；交通速度没有玩法倍率上限。所有参数仍交给原来的原生补丁实现。

## 补丁执行边界

- `GameService.Options` 将模型转换为原增强器的 18 个选项。
- 原增强器依赖 Framework 的 `System.Web.Extensions`，直接加载到现代 .NET 会出现 `Utf16StringValidator` 类型错误。`PatchBridge.cs` 因而在单独 Framework 进程中反射调用它，通过临时 XML 请求和结果交换数据。
- 只读检查不修复或重写游戏状态；用户点击应用后才允许应用补丁及处理 Steam 恢复后的过期状态。兼容进程错误会返回界面日志。
- “应用并启动”先应用文件补丁、保存配置，再启动游戏并调用既有 `RuntimePatch.Apply`。运行时补丁失败会保留界面并说明游戏已启动，避免将部分失败报告为成功。
- `--watch`、音频诊断及透明汽车叠加仍复用现有实现。背景程序从当前自包含 EXE 启动，工作目录为所选游戏目录。

## 构建与分发

开发需要 Windows、.NET 10 SDK、Windows 自带 Framework 编译器；首次构建需要 NuGet。`build.ps1` 优先使用项目 `artifacts/tools/dotnet` 中的便携 SDK，也接受 `-DotNet` 指定路径。`-BuildOnly` 编译调试产物，默认发布自包含版本。

分发面向 Windows 10/11 x64。`暴力摩托增强启动器.exe` 自带 .NET/WPF 运行库，`Tools/RoadRash.PatchBridge.exe` 使用系统 Framework 4.x。将启动器和整个 `Tools` 文件夹安装到现有游戏目录。玩家版随附已验证的 v1.1.0 增强器。

`package.py` 使用明确白名单，输出源码包、启动器包、清单与 SHA-256。不包含游戏、个人 INI、补丁状态文件、开发 SDK、NuGet 缓存或隔离测试副本。升级保留已有 INI；通用配置以示例文件名提供，防止解压时覆盖玩家配置。

## 验证范围

- 原有原生回归：1520 项通过，涵盖长跑、AI、交通、翻滚、声音、碰撞及原游戏映射代码；未启动游戏。
- 新模型：默认值全量比对、重置/撤销、INI 往返、旧配置迁移、参数转换、无上限交通倍率、跑速精度、字段依赖和预设识别。
- 离屏 WPF：八个页面在 1280×800 和 1064×660 内容尺寸渲染，检查顶部、底部与展开高级项；验证实际编辑控件到模型/摘要的双向绑定。
- 隔离桥接：从已有补丁基线复制原始文件到新测试目录，检查 18 个选项全部应用，然后还原并比对原始文件哈希，同时验证现代进程调用 Framework 的边界。

`scripts/test-wpf.ps1 -RenderUi` 只创建离屏内容树，不显示或激活桌面窗口。加 `-GameDirectory` 执行隔离桥接检查，须存在原增强器生成的基线。此迁移未验证真实游戏启动后的整场游玩；实机测试须事先告知正在工作的用户。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `src/Wpf/MainWindow.xaml`、`Theme.xaml` | 工作台布局与控件外观 |
| `WorkbenchViewModel.cs` | 导航、命令、摘要、草稿和重置撤销 |
| `Settings.cs`、`Schema.cs` | 参数模型、校验、预设与兼容读取 |
| `GameService.cs` | 文件补丁、进程启动、原生参数传递 |
| `src/PatchBridge.cs` | 原增强器的 Framework 兼容进程 |
| `OfflineVerification.cs`、`scripts/test-wpf.ps1` | 模型、控件绑定、渲染及隔离集成验证 |

原生补丁函数及机器码不因 UI 迁移重新实现。共享源文件只开放了 CLI 入口并明确了 WinForms 文件选择框的类型，避免与 WPF 同名类型冲突。
