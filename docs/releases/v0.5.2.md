# 暴力摩托增强修改器 0.5.2

## 长跑起步与交通

- **密集起跑。** 修复开启 AI 选线时，前排少数选手已经跑出、大部分人还挤在原地的问题。并排的跑者会调整路线，跟随前方选手时也能迈步。
- **长跑碰撞。** 游戏会自动跳过用于引导跑者的摩托车的多余碰撞检查。人物、交通车和已恢复骑行的摩托照常参与碰撞。
- **疯狂司机。** 在「道路与交通」中开启后，同向和对向普通交通车会自行变道，可能冲上路肩。前方有行人或选手时也照常行驶，撞上仍可将选手撞倒。该选项默认关闭。

在万人密集起跑的离线对照中，使用 1 倍跑速和中档选线，队列里第一步就向前移动的跑者从 9,999 人中的 36 人增加到全部 9,999 人。这项测试单独验证起步逻辑，整场帧率仍取决于赛道、人数和硬件。

## 下载与安装

适用于 Windows 10/11 64 位和 Steam《Road Rash：30 周年纪念版》，本版验证使用游戏 build **26105967**。

| 附件 | 用途 |
| --- | --- |
| `RoadRash30th-EnhancedMod-0.5.2-player.zip` | 玩家版，内含修改器、增强器 v1.1.0 和运行库。首次安装选这一份。 |
| `RoadRash30th-EnhancedMod-0.5.2-standalone.zip` | 独立修改器版，自带运行库，沿用游戏目录中的 `Tools/RoadRash30thEnhancement-v1.1.0.exe`。 |
| `RoadRash30th-EnhancedMod-0.5.2-source.zip` | 修改器源码、构建脚本、测试和文档。 |

退出游戏和修改器，将玩家版或独立版完整解压到 `RoadRash95.exe` 所在目录，覆盖包内同名文件。打开 **暴力摩托增强修改器.exe**，选好玩法后点击 **应用并启动**。升级可沿用个人配置、存档、语音库和原有快捷方式。每份 ZIP 附同名 SHA-256 校验文件。
