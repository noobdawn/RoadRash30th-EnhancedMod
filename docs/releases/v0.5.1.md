# 暴力摩托增强修改器 0.5.1

单人比赛起跑时，大批车手同时更新名次会造成停顿。这个版本默认开启「Fix 修复 → 减少大型比赛卡顿」，玩家自己的名次照常更新。从旧版升级会保留已保存的选择。

两场万人比赛实测都从起跑阶段的首次名次计算开始记录，前 300 个模拟步各处理了 41,428 次名次请求。开启优化后，这些请求的总耗时从 **525.42 毫秒降至 42.03 毫秒**，减少约 **92%**。这组数据只统计名次计算耗时。

## 下载与安装

适用于 Windows 10/11 64 位和 Steam《Road Rash：30 周年纪念版》。已验证游戏 build **26105967**。

| 附件 | 适用情况 |
| --- | --- |
| `-player.zip` 玩家版 | 内含修改器和增强器 v1.1.0，可直接解压安装。 |
| `-standalone.zip` 独立修改器版 | 已有增强器时可选。游戏目录中应有 `Tools/RoadRash30thEnhancement-v1.1.0.exe`。 |
| `-source.zip` 源码 | 用于查看或自行构建本版代码。 |

1. 退出游戏和修改器。在 Steam 库中右键游戏，选择「管理 → 浏览本地文件」。
2. 将所选玩家版或独立修改器版 ZIP 的全部内容解压到 `RoadRash95.exe` 所在目录，允许覆盖包内同名文件。
3. 打开 **暴力摩托增强修改器.exe**，选好玩法后点击 **应用并启动**。原来指向「暴力摩托增强启动器.exe」的快捷方式仍可使用，个人设置和语音库可继续沿用。

两个可运行版本均自带 .NET 桌面运行库。详细玩法与还原步骤见包内 `安装说明.txt`。每个 ZIP 都附有同名的 `.sha256.txt` 校验文件。
