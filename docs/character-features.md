# 车辆耐久与下车人物选项

2026-11-17，适配 Steam build 26105967。

## 使用

- 高级 → 车辆与碰撞 → 车辆耐久：车辆无限耐久，仅玩家生效。正常、车辆、泥头车、长跑四个比赛预设均默认开启；手动关闭后显示“自定义”。人物生命、霸体和翻车选项独立。
- 高级 → 玩家与战斗 → 下车后的人物移动与防护：玩家和 AI 跑速分别设置，取消 8 倍上限，可直接输入 10、50、100 等倍率，最低 0.1，步长 0.1，默认 1.0。只改变起身后的跑动速度，骑车和抛飞速度不变；长跑屏幕外模拟也使用对应倍率。
- 同一分组中开启“下车后不会被撞倒”，可选“仅玩家”或“所有人（玩家与 AI）”。默认关闭。保护已起身的人物，不阻止第一次翻车，不取消正常上车流程。
- 同一分组新增“倒地后隐藏车辆”，对玩家与 AI 生效：摔车、跑步及上车过渡期间不绘制车辆与车影，重新骑上后恢复。人物照常显示，车辆位置、碰撞、追车和上车逻辑保留。长跑预设默认开启，正常、车辆、泥头车预设默认关闭，可独立调整。汽车外观启用时，下车后显示原人物。
- 更改后点击“应用并启动”，在新启动的游戏进程生效。

配置版本为 6：`infiniteDurability=1`、`playerWalkSpeed=1.0`、`aiWalkSpeed=1.0`、`onFootProtection=0`、`onFootScope=0`，新增 `hideFallenVehicles=0`。范围值 0 为玩家、1 为所有车手。旧配置缺少隐藏选项时，按 `longRun` 是否开启确定默认值；手动保存的开关优先。速度不再截到 8 倍，非法文本恢复 1.0。仅保留原生有符号 32 位速度字段的表示边界：倍率最多 1789569.7，乘以 1200 后不溢出字段；该表示上限不等于超高倍率物理行为经过实机验证。

## 实现与验证

源码为 `src/LauncherCharacter.cs`，由 `RuntimePatch.Apply` 在启动游戏后安装。独立分配 0x1000 代码区，每入口预留 0x200；先检查全部启用入口签名，再写代码及跳转。签名不匹配会报错。运行时地址使用模块基址加 RVA，游戏磁盘文件不由这些新选项修改。

| RVA | 用途 |
| --- | --- |
| 0x137CC | 碰撞/战斗损坏的车辆耐久扣减，ESI 为 bike；玩家改取最大耐久 +0x2EC，原后续写入当前耐久 +0x2F0。人物生命扣减保留。 |
| 0x14792 | 车辆磨损扣减，保护玩家并保留 EDX 指向当前耐久的约定。 |
| 0x17D7F | 人车分处道路边界的强制报废路径；玩家跳到 0x17D9F，跳过报废通知及耐久清零。 |
| 0x17ED7 / 0x1A12C | 两条跑动速度赋值路径，分别以 EDI / EBX 为 rider；每次由原始 1200 设置倍率值，不逐帧累乘。 |
| 0x13F8A | 下车人物碰撞回调；受保护人物跳到原尾部 0x141D2，保留冲量清零、速度限幅及剩余路程更新。 |
| 0x4AD4A | 车辆绘制回调分发前：只跳过类型 4 且状态 1–3 的车体回调，不改人物或交通车。位于屏幕坐标捕获入口之前。 |

跑速和防撞保护检查 rider 类型 8、所属 bike 类型 4、bike 的 +0x2F4 状态为 2（起身跑动）。玩家用模块 +0x1A69EC 的 bike 指针识别。状态 0（骑车）、1（倒地/抛飞）、3（上车过渡）走原行为。所有人指玩家和 AI 车手，非赛道装饰人物。

`tests/CharacterTests.cs` 执行实际生成的 x86 代码，覆盖耐久的玩家/非玩家路径、两条跑动路径的独立倍率与连续帧、上下界、骑行/抛飞/上车状态、空关联、保护范围、寄存器/标志/堆栈及安装签名。带游戏目录时还检查六个真实入口，映射游戏 PE 并执行原碰撞函数：关闭保护时状态 2→1，保护后保持 2；保留原尾部和剩余路程更新调用，清除三项待应用冲量。

完整验证命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test.ps1 -GameDirectory .. -RenderUi
```
